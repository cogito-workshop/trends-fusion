# .minimax Directory

This directory contains AI-generated documentation and files created during development.

## Structure

- `docs/` - General documentation files
- `reports/` - Bug reports and completion reports
- `plans/` - Development plans and roadmaps
- `data-collection/` - Data collection module documentation
- `migration/` - Database migration related files
- `misc/` - Miscellaneous project files

## Purpose

These files are automatically generated during development and are kept separate from the core project files to maintain a clean project root.
