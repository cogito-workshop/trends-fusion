## 🔧 技术特性

### 配置检查逻辑
```typescript
// 应用启动时检查
const isConfigured = await window.aiTrendPublish.config.isConfigured();
if (!isConfigured) {
  // 显示配置向导
  return <SetupWizard />;
}
// 否则进入主应用
```

### 聊天交互流程
1. **欢迎消息** → AI助手自我介绍
2. **配置请求** → 逐个询问缺失的配置
3. **用户输入** → 验证并保存到数据库
4. **确认消息** → 显示保存成功提示
5. **下一项** → 循环直到所有配置完成
6. **完成庆祝** → 显示完成界面
